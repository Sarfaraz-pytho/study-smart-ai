# 🚀 StudySmart AI — Smart School Assistant

## 📌 About

StudySmart AI is a Python-based smart school assistant designed to help students study in a simple and distraction-free way.

It helps users find study resources, practise questions, clear doubts, and receive study recommendations and plans.

## ✨ Features

* 📚 Find study resources
* 📝 Practice quizzes
* ❓ Ask and clear doubts
* 💡 Get smart study recommendations
* 📅 Create personalised study plans
* 🎯 Subject and topic-based learning

## 🛠️ Technologies Used

* Python
* Python Dictionaries
* Lists
* Functions
* Loops
* Conditional statements
* User input and output

## ▶️ How to Run

1. Download or clone this repository.
2. Make sure Python is installed.
3. Open a terminal in the project folder.
4. Run:

```bash
python src/main.py
```

## 🎮 How to Use

1. Start the program.
2. Enter your name.
3. Select an option from the main menu.
4. Choose a subject or topic when required.
5. Use the available features to study, practise, and clear doubts.

## 🧠 How It Works

StudySmart AI currently uses a rule-based Python approach.

The project stores resources, questions, and other learning information using Python data structures such as dictionaries and lists. The program uses functions, conditions, loops, and user input to provide an interactive study experience.
